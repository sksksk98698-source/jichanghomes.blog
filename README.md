# Jichang Homes (吉长之家)

> 独立原创技术博客与知识分享平台 · 基于 Astro 的极简、极速、无暗桩纯净架构。

## 核心特性

- **100% 独立与纯净**：彻底剔除外部第三方探针、暗桩与非必要依赖，所有内部静态资产均本地化自洽托管。
- **现代化技术栈**：基于 Astro 极速静态渲染体系构建，搭配 32 套终端轻量调色板与原生 CSS 自定义属性。
- **零外部请求与静态检索**：集成本地 Pagefind 客户端离线全文检索，隐私安全无追踪。
- **全链路 SEO 优化**：规范化 Canonical 链接、完整 Schema.org 结构化数据 (JSON-LD)、精准 Sitemap 及 OpenGraph 社交卡片。

## 本地开发与构建

```bash
# 安装依赖
npm install

# 启动本地开发服务 (支持即时热更新与 Pagefind 索引调试)
npm run dev

# 静态生产构建与全文搜索索引生成
npm run build

# 生产环境预览
npm run preview

# 类型与代码完整性检查
npm run check
```
