随着 Clash 原版核心作者于 2023 年底停更归档，开源社区全面转向以 **Mihomo (Clash.Meta)** 为代表的现代化新内核。其中，**Clash Verge Rev** 凭借跨平台一致的现代 UI、原生 TUN 模式与活跃的社区维护，已稳居 Windows 与 macOS 双平台的装机主力。而在苹果 iOS 生态中，**Shadowrocket（小火箭）** 依然是不折不扣的统治级工具。

本文将手把手指导大家如何在 Windows/Mac 上配置 Clash Verge Rev，以及在 iPhone 上配置 Shadowrocket，实现**海外学术/流媒体智能加速，国内应用（微信、网银、腾讯视频等）不走代理直连**的无感分流效果。

## 第一部分：Windows & Mac 配置 Clash Verge Rev

### 步骤 1：下载安装官方正版
前往 GitHub 官方 Release 页面下载安装包：
- Windows 用户：下载 `.msi` 或 `x64-setup.exe` 安装文件。
- Mac 苹果芯片（M1/M2/M3/M4）用户：下载 `aarch64.dmg`。
- Mac Intel 芯片用户：下载 `x64.dmg`。

### 步骤 2：获取并导入机场订阅
1. 登录您所使用的机场后台（如 [光速云](/airports/guangsu/)、[暮光加速](/airports/muguang/) 等），在“仪表盘”或“订阅导入”区域点击 **「复制 Clash 订阅链接」**。
2. 打开 Clash Verge Rev，点击左侧菜单栏的 **「订阅 (Profiles)」**。
3. 在顶部输入框粘贴刚才复制的订阅 URL，点击右侧 **「导入 (Import)」**。
4. 导入成功后，鼠标左键点击该订阅卡片，卡片变为高亮即表示当前已激活生效。

### 步骤 3：选择节点与开启代理
1. 点击左侧 **「代理 (Proxies)」**，展开代理组（如 `PROXY` 或 `节点选择`）。
2. 点击右上角 Wi-Fi 图标进行批量延迟测速，选择一个延迟低、标记为香港/新加坡/日本的优质节点。
3. 返回主界面或任务栏托盘，开启 **「系统代理 (System Proxy)」**。
4. **进阶推荐技巧：开启 TUN 模式**
   在「设置 (Settings)」中勾选 **「TUN 模式」**（需管理员权限授权安装虚拟网卡）。开启 TUN 模式后，即使用户在命令行终端执行 `git clone`、`npm install`，或者使用部分不遵循系统代理的海外原生客户端软件，都会被自动接管加速，省去手动配置端口的麻烦。

## 第二部分：iPhone / iPad 配置 Shadowrocket（小火箭）

### 步骤 1：准备外区 Apple ID 并下载
Shadowrocket 无法在大陆 App Store 上架。请先准备一个美区或港区 Apple ID：
1. 打开 iPhone 自带的 App Store，点击右上角头像滑到底部，退出当前账号。
2. 登录美区/港区 Apple ID（**千万注意：仅在 App Store 登录，绝对不要在手机系统设置 iCloud 处登录！**）。
3. 搜索 **Shadowrocket**（售价通常为 $2.99 美金），完成购买并下载安装。

### 步骤 2：一键导入订阅配置
1. 手机 Safari 浏览器登录机场后台，大部分现代机场均提供 **「一键导入 Shadowrocket」** 按钮，点击即可自动唤醒小火箭并写入节点列表。
2. 若需手动导入：
   - 在机场后台点击“复制小火箭/通用订阅链接”。
   - 打开 Shadowrocket，点击右上角的 **「+」** 号。
   - 类型选择 **「Subscribe」**，在 URL 栏粘贴链接，备注填写机场名称（如“光速云”），点击右上角“完成”。
   - 小火箭将自动拉取并展开全部可用节点列表。

### 步骤 3：分流策略设置与连接
1. 在首页中部的 **「全局路由」** 选项中，务必确认为 **「配置 (Config)」** 模式。
   - ⚠️ 绝不能选“全局代理 (Proxy)”，否则访问国内百度、微信、网银等所有本地流量也会绕行海外，不仅速度极慢，而且浪费机场流量。
   - 选择“配置”模式后，软件会自动根据内置的大陆 IP 与域名白名单进行智能分流：访问 Google/YouTube 自动翻墙，访问淘宝/微信自动直连。
2. 挑选一个测速延迟较低的节点，点击选中（节点前出现黄色圆点）。
3. 滑动顶部的主开关，首次连接时系统会弹出提示“Shadowrocket 想添加 VPN 配置”，点击“允许”并验证面容 ID 或锁屏密码即可成功连通。

## 常见疑难排查与避坑指南

1. **导入订阅提示超时或错误（Invalid URL）**：
   - 检查复制的订阅链接是否有前缀空格。
   - 检查当前本地 Wi-Fi 是否屏蔽了海外机场的域名，可尝试切换手机 5G 热点重新下载配置。
2. **连接后网页打不开但测试有延迟**：
   - 检查电脑或手机本地时间是否准确。若本地时钟与标准网络时间相差超过 90 秒，TLS 加密握手将会被强制中断。
   - 在客户端设置中清空一次 DNS 缓存并重启客户端。
3. **节点频繁掉线或跳 ping**：
   - 这通常是由于机场本身使用了廉价公网直连中转，建议更换为具备 **IEPL/IPLC 跨境物理专线** 的高可靠机场（可参考本站 [42 家机场品牌库](/airports/) 或 [测速实验室](/speedtest/) 的实测榜单）。
