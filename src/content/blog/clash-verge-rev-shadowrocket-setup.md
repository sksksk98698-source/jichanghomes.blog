随着 Clash 原版核心作者于 2023 年底停更并归档代码仓库，全球开源代理社区全面转向以 **Mihomo (原 Clash.Meta)** 为代表的现代化新内核。在这一技术演进浪潮中，**Clash Verge Rev** 凭借现代化跨平台 UI、原生集成 TUN 虚拟网卡驱动与极高频的开源社区维护，迅速成为 Windows 与 macOS 双平台的绝对装机主力。而在苹果 iOS 生态中，老牌王者 **Shadowrocket（小火箭）** 依然凭借极高的稳定性与丰富的分流规则占据统治地位。

然而，许多读者在初次使用这些工具时，经常陷入“连接成功却打不开网页”、“本地微信和网银频繁掉线被风控”、“命令行终端与游戏无法走代理”等诸多困扰。

作为独立网络技术观察平台，**[机场homes (jichanghomes.blog)](/)** 实验室编写了这份长篇保姆级实操指南，手把手带您完成从零安装、订阅导入、规则分流调优、TUN 模式启用一直到家庭全屋软路由透明代理的全流程部署。

## 二、Windows & macOS 平台：Clash Verge Rev 保姆级实操

### 步骤 1：下载安装正版客户端与防钓鱼鉴别
当前搜索引擎中充斥着大量夹带木马、捆绑推广软件的虚假第三方下载站。请务必前往官方 GitHub 仓库 Release 页面获取纯净安装包：
- **Windows 用户**：优先下载 `.msi` 或 `x64-setup.exe` 架构安装文件。
- **Mac 苹果芯片（M1/M2/M3/M4）**：必须下载包含 `aarch64.dmg` 标识的安装包，以获得原生 ARM 架构的最高能效比。
- **Mac Intel 芯片**：下载 `x64.dmg` 安装包。

### 步骤 2：获取并导入机场订阅配置
1. 登录您所使用的正规机场后台（如本站第一主推的 [光速云 IEPL 专线](/airports/guangsu/) 或 [暮光加速](/airports/muguang/)）。
2. 在用户中心仪表盘找到“订阅导入”区域，点击 **「复制 Clash 订阅链接」**。
3. 打开 Clash Verge Rev，点击左侧菜单栏的 **「订阅 (Profiles)」**。
4. 在顶部 URL 输入框中粘贴刚才复制的订阅链接，点击右侧的 **「导入 (Import)」** 按钮。
5. 导入成功后，鼠标左键点击刚才生成的配置卡片。卡片边框高亮变色，即表示该订阅配置已在内核中成功挂载。

### 步骤 3：选择优质低延迟节点与分流模式
1. 点击左侧导航栏的 **「代理 (Proxies)」** 页面。
2. 展开主代理策略组（通常命名为 `PROXY`、`节点选择` 或 `自动选择`）。
3. 点击右上角的 Wi-Fi 测速图标，系统会对列表中的所有专线节点进行并发 RTT 测速。
4. 建议优先勾选显示绿色低延迟的 **香港 (HK)、新加坡 (SG) 或日本 (JP)** 节点。
5. 返回主界面或任务栏系统托盘，右键开启 **「系统代理 (System Proxy)」**，此时打开浏览器即可顺畅访问海外学术站点与 Google。

### 步骤 4：进阶必学技巧 —— 开启 TUN 虚拟网卡模式
很多开发者经常遇到这样的痛点：在浏览器里能打开 GitHub，但在 CMD 终端执行 `git clone`、`npm install`，或者在 VS Code 里调用 Cursor / Copilot 时，依然报错网络连接超时。

这是因为“系统代理”仅对遵循 Windows/macOS 系统代理规范的普通应用程序生效。而开启 **TUN 模式** 可以彻底解决这一顽疾：
1. 在 Clash Verge Rev 左侧进入 **「设置 (Settings)」**。
2. 找到 **「TUN 模式 (TUN Mode)」** 开关，点击开启（首次开启时 Windows 会弹出 UAC 提权请求，Mac 会要求输入锁屏管理员密码以安装虚拟网卡扩展驱动）。
3. 开启后，系统网络适配器中会生成一张虚拟网卡（Meta Core TUN Adapter），**接管本机操作系统所有的 TCP 与 UDP 流量**。
4. 此时无需对命令行设置任何复杂的 `export http_proxy`，全系统所有软件自动享受无感极速加速！

## 三、苹果 iOS 平台：Shadowrocket（小火箭）实战全解

### 步骤 1：准备非国区 Apple ID
Shadowrocket 无法在大陆 App Store 上架。请准备一个美区或港区 Apple ID：
1. 打开 iPhone 自带的 App Store，点击右上角头像滑到最底部，点击“退出登录”。
2. 登录准备好的美区/港区账号。
3. 搜索 **Shadowrocket**（正版开发者为 Pan 国斌，图标为白色小火箭配深黄底色，售价通常为 $2.99 美金），完成购买并下载。
4. **⚠️ 避坑红线警告**：海外 Apple ID **只能在 App Store 登录，绝对禁止在 iPhone 系统“设置 -> iCloud”处登录**！一旦使用公共 ID 登录 iCloud，可能导致手机被他人远程锁机变砖。

### 步骤 2：导入订阅配置与节点同步
1. 使用 Safari 浏览器登录机场后台，大部分现代机场均支持 **「一键导入 Shadowrocket」**，点击后系统将自动唤醒小火箭并将全部节点写入。
2. **手动添加订阅方法**：
   - 打开小火箭首页，点击右上角 **「+」** 号。
   - “类型”选择 **「Subscribe」**。
   - 在“URL”一栏粘贴机场提供的通用订阅链接，备注栏输入机场名字（如“光速云”），点击右上角“完成”。
   - 首页将自动展开所有专线节点并显示当期套餐到期日与剩余流量。

### 步骤 3：核心分流设置 —— 务必保持“配置 (Config)”模式
在 Shadowrocket 首页中间，找到 **「全局路由」** 选项，这里决定了流量的分流走向：
- **配置 (Config) 模式【强烈推荐】**：软件自动依据内置的规则白名单（China Max）运行。访问 Google、YouTube、Twitter、ChatGPT 自动走代理节点；访问微信、淘宝、本地银行 App 自动走国内直连。既不浪费机场流量，又不会触发网银风控。
- **代理 (Proxy) 模式【严禁日常开启】**：全局所有流量绕行海外，会导致打开百度极慢，且极其耗费流量。
- **直连 (Direct) 模式**：所有流量不走代理，相当于关闭翻墙。

挑选一个测速绿色的香港节点，打开顶部主连接开关，首次授权输入锁屏密码，右上角状态栏出现 `VPN` 图标即表示连接成功。

## 四、家庭全屋智能出海：OpenWrt 软路由透明代理实战

对于拥有 Apple TV 4K、PlayStation 5、Xbox 主机或全屋智能家居的家庭，在每台设备上单独配置客户端极其繁琐。在软路由上部署透明代理是最优雅的终极形态：

### 1. Fake-IP 模式解析机制与 0ms DNS 原理
在 OpenClash 插件设置中，强烈建议将运行模式设置为 **「Fake-IP 增强模式」**：
- **传统 DNS 弊端**：设备请求海外域名时，需等待本地公共 DNS 解析出真实 IP，由于中间存在 GFW 投毒与网络丢包，DNS Lookup 耗时往往长达数百毫秒。
- **Fake-IP 优雅之处**：当终端设备请求 `youtube.com` 时，路由器本地在 0 毫秒内立刻返回一个虚构的保留局域网 IP（如 198.18.0.22）。终端设备直接向该 IP 发送数据包，数据包进入软路由后，由 OpenClash 在海外落地端解析真实目标地址。全家所有终端彻底摆脱国内 DNS 投毒干扰，网页秒开体验极其惊艳。

### 2. 主机联机加速与 FullCone NAT 穿透
对于主机游戏联机，必须在 OpenClash 设置中勾选 **「启用 FullCone NAT 模式」**。配合我们在 [2026 机场选购指南](/blog/2026-airport-selection-guide/) 中推荐的优质企业专线，可以让 PS5 与 Switch 获得 NAT Type A/B 评级，告别游戏组队排不到人的尴尬。

## 五、Android 手机深度调优：分应用代理与防杀后台

安卓系统由于各手机厂商（小米 MIUI/HyperOS、华为 HarmonyOS、vivo OriginOS、OPPO ColorOS）严格的省电机制，经常会在手机锁屏 5 分钟后自动杀死后台代理进程，导致微信接收延迟。

### 1. 开启分应用代理 (Split Tunneling)
在 v2rayNG 或 Clash Meta for Android 设置中，开启“分应用代理”：
- 勾选模式设为“仅代理选中的应用”。
- 仅将 Chrome 浏览器、YouTube、Telegram、ChatGPT、X (Twitter) 等海外软件加入代理列表；
- 微信、企业微信、钉钉、高德地图、支付宝等国内应用彻底从 VPN 流量中剥离。

### 2. 安卓系统电池优化与常驻后台锁定
1. 进入系统“设置 -> 应用管理 -> 权限管理”，找到代理客户端。
2. 将“省电策略”从“智能推荐”修改为 **“无限制 / 允许后台高耗电运行”**。
3. 允许“自启动”与“关联启动”。
4. 在手机多任务卡片界面，下拉客户端卡片并点击“锁定”小图标，确保清理后台时进程不被误杀。

## 六、网络连接异常与排障标准工作流程（7 步排错树）

当您遇到“已连接但打不开网页”或“所有节点均显示 Timeout”时，请依照以下专业 SOP 快速自检：

1. **步骤 1：同步本地系统时钟 (NTP)**：如果本地时间误差超过 60 秒，TLS 加密握手直接失效并报 SSL 证书错误。请在系统设置中点击“立即同步时间”。
2. **步骤 2：测试国内网络物理通断**：先关闭代理开关，在浏览器打开百度或哔哩哔哩。若国内网页同样无法打开，说明是光猫断网或 Wi-Fi 断开。
3. **步骤 3：排查系统代理端口冲突**：检查是否后台同时开启了其他旧代理软件（如 Fiddler、Charles 或其他加速器），避免 7890 核心端口被抢占。
4. **步骤 4：刷新本地 DNS 缓存**：在 Windows 命令行执行 `ipconfig /flushdns`，清除过期的解析残留。
5. **步骤 5：排查 QUIC 协议阻断**：若 Google 能打开但 YouTube 提示无网络，在 Chrome 输入 `chrome://flags` 将 `Experimental QUIC protocol` 设为 Disabled。
6. **步骤 6：从官网后台重拉最新订阅配置**：部分节点可能因防封锁升级轮换了后端接入域名，更新订阅即可拉取最新可用节点池。
7. **步骤 7：工单支持与备用梯切换**：若仍未恢复，可切换至备用机场（参考 [42 家机场品牌库](/airports/)），并向服务商客服提交技术工单。

## 七、7 个高价值配置 FAQ

### Q1：为什么开启 TUN 模式后电脑无法访问局域网打印机或 NAS？
在 Clash Verge Rev 的 TUN 模式高级设置中，勾选 **“严禁路由私有网络 (Strict Route)”** 并将局域网网段（如 `192.168.0.0/16`, `10.0.0.0/8`）加入 Direct 直连列表，即可恢复局域网共享与 NAS 互通。

### Q2：Clash Verge Rev 提示“Service Mode 失败”怎么办？
右键点击 Clash Verge Rev 快捷方式，选择 **“以管理员身份运行”**，进入设置界面重新点击安装服务模式（Service Mode），安装完毕后重启软件即可。

### Q3：同一份订阅可以在几台设备上同时导入？
这完全取决于您购买的机场套餐规则。例如本站推荐的 [光速云](/airports/guangsu/) 明确标注不限在线设备数，一份订阅可以同时在手机、笔记本与软路由上无缝使用；部分按设备数收费的小机场则限制 2~3 台设备并发。

### Q4：为什么有时访问 ChatGPT 会提示 403 阻断？
OpenAI 对机房 IP 风控极严，此时只需在代理节点列表中将节点手动切换至新加坡、日本或美国其他原生落地节点即可恢复。

### Q5：如何防止 Shadowrocket 在后台偷跑流量？
确保全局路由选择为“配置”模式，并在设置中关闭“自动更新订阅”中的高频轮询，避免手机在移动数据下产生额外后台开销。

### Q6：使用 TUN 模式玩海外游戏，延迟为什么比商业游戏加速器稍高？
游戏加速器通常专门优化了特定游戏服务器的 UDP 专线链路；而通用机场更侧重全网吞吐与内容加载。若追求竞技低延迟，可选择像 [光速云香港 22ms 专线](/airports/guangsu/) 这类高质量 IEPL 线路节点。

### Q7：软件提示“YAML Parse Error 配置文件解析错误”怎么修？
通常是因为订阅链接中包含特殊字符、前缀空格，或者由于机场服务器临时故障返回了 HTML 错误页面。请重新核对复制链接，或使用第三方订阅转换工具将订阅标准化为 Clash 格式后再行导入。
